# Support

Для ошибок и запросов функций используйте GitHub Issues.

Перед созданием Issue:

1. проверьте актуальный Release и документацию;
2. укажите версию InboxWeaver и почтового клиента;
3. приложите минимальные шаги воспроизведения;
4. удалите из логов адреса, содержимое писем, имена вложений и локальные пути.

Для вопросов по использованию подходит GitHub Discussions после его включения в настройках репозитория.

Уязвимости безопасности не публикуйте в обычных Issues — используйте инструкции из [SECURITY.md](SECURITY.md).
