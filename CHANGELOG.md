# Changelog

Все значимые изменения проекта фиксируются в этом файле.

## 2.0 — 24 сентября 2026

### Release

- Релизная версия собрана на кодовой базе тестового кандидата `1.0.230` (`test62`). Изменений логики обработки писем и формата пользовательских данных в переходе `1.0.230 → 2.0` нет.
- Версия в `manifest.json` изменена на `2.0`; документация, руководство пользователя и навигация по истории проекта сведены в единый комплект.
- Проект опубликован по открытой лицензии MIT с указанием автора.
- Статус ручной приёмки в целевом почтовом клиенте указан отдельно от автоматических проверок. Само изменение номера версии не подтверждает сценарии P-001–P-057.

## 1.0.230

### Fixed

- При формировании ручного и автоматического XLSX-отчёта старые записи без сохранённого `headerMessageId` повторно читают RFC-заголовок `Message-ID` через временный ID Thunderbird. В колонку `message_id` внутренний ID никогда не попадает.
- Восстановление заголовков ограничено восемью параллельными запросами к Thunderbird; ошибка одного запроса не срывает экспорт.

### Tests

- Добавлены проверки восстановления RFC `Message-ID` и отсутствия подмены его внутренним ID Thunderbird.
- Добавлена проверка ограничения параллелизма и синхронной ошибки адаптера Thunderbird.

### Release artifact

- Тестовая сборка `test62`, commit `5d6ec16eb9f13204aa2aeeffbf7723ad83f6a4d1`, SHA-256 `8f65e477ca24e8a48a1141408160d3f4dfe79f3f3c25038383713fecaeab72d8`.
- Автоматические проверки исходного кандидата: 144 теста по описанию test62; ручная приёмка не завершена.
