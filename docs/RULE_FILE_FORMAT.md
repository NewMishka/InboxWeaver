# Формат файла правил

Правила сохраняются в JSON-файл. Его можно открыть и изменить в любом текстовом редакторе, затем загрузить через страницу «Правила обработки».

```json
{
  "format": "inbox-weaver-rules",
  "format_version": 1,
  "rules": [
    {
      "name": "Счета PDF",
      "enabled": true,
      "when": "from:supplier@example.com AND fileext:pdf",
      "scan": {
        "accounts": ["account-1"],
        "folders": ["account-1::Inbox"]
      },
      "save": {
        "folder": "Счета",
        "mode": "by_rule",
        "base_path": "Финансы"
      }
    }
  ]
}
```

- `name` — понятное имя правила.
- `enabled` — `true` для активного и `false` для выключенного правила.
- `when` — условие в том же синтаксисе, что используется в редакторе правил.
- `scan.accounts` и `scan.folders` — идентификаторы ящиков и папок текущего почтового профиля.
- `save.folder` — папка результата; `save.mode`: `combined`, `by_rule`, `by_sender`, `by_account` или `by_date`.
- `save.base_path` — дополнительная подпапка, необязательное поле.

До записи импорт проверяет JSON, формат файла и каждое правило. Можно заменить текущий набор или добавить импортированные правила к нему; операция замены требует явного подтверждения.

## Сложные условия

Поддерживаются `AND`, `OR`, исключение `-` и скобки. Если исключение должно относиться ко всем вариантам условия, заключите варианты в скобки:

```text
(subject:счёт OR fileext:pdf) AND -from:blocked@example.com
```

Кнопка «Добавить ещё условие» в редакторе делает это автоматически: она объединяет уже собранное правило и новое условие через `AND` со скобками вокруг обеих частей.
