# Baseline

| Роль | Версия | Основание |
|---|---|---|
| Production reference | `1.0.162` | Последняя зафиксированная рабочая точка сравнения; хранить для отката. |
| Исходный кандидат 2.0 | `1.0.230 / test62` | Тестовый релиз, commit `5d6ec16eb9f13204aa2aeeffbf7723ad83f6a4d1`. |
| Версия выпуска | `2.0` | Только номер и документация поверх 1.0.230; XPI и SHA-256 указываются в релизе. |

До заполнения P-001–P-057 новая версия не считается подтверждённой production baseline. Существующие пользовательские данные старой линии не импортируются автоматически в новую статистику. Архивные `1.0.146` и `2.2.5l` не являются основой 2.0.
