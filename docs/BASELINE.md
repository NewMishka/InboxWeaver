# Baseline

| Роль | Версия | Основание |
|---|---|---|
| Historical production reference | `1.0.162` | Последняя зафиксированная рабочая точка сравнения из приватной линии разработки. |
| Функциональная база 2.0 | `1.0.230 / test62` | Исторический тестовый кандидат, на котором основана функциональность 2.0. |
| Публичный выпуск | `2.0` | GitHub pre-release `v2.0`, commit `f5d6c90`, XPI и SHA-256 опубликованы в Release. |

Публичная версия 2.0 не объявляется production baseline до завершения ручного протокола P-001–P-057.

Автоматические тесты подтверждают регрессионные контракты проекта, но не заменяют проверку реального почтового клиента, файловой системы и почтовой синхронизации.
