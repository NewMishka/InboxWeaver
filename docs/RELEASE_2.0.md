# InboxWeaver — Менеджер писем 2.0 — заметки релиза

## Происхождение

Версия 2.0 подготовлена на основе проверенной исторической линии 1.0.230 / test62 из приватного архива разработки. Между 1.0.230 и 2.0 нет изменений в обработке писем, правилах или хранилище: изменён номер `manifest.json`, объединены документация и инструкция по использованию. Архивная линия `2.2.5l` не является основой этой сборки.

## В составе 2.0

- Правила для нескольких ящиков и папок, Live и догоняющая проверка.
- Ручное сохранение вложений и защита от дублей SHA-256.
- Статистика, фильтры, группировки, пагинация и XLSX-отчёты, в том числе по расписанию.
- Прерываемый полный обход с обработкой тайм-аутов и локальных ошибок.
- Корректное исключение отправителя в сложном правиле с OR и восстановление RFC Message-ID в старых записях отчёта.
- Обновлённые [главная страница](../README.md), [руководство](USER_GUIDE.md), [история](RELEASE_HISTORY.md), [CHANGELOG](../CHANGELOG.md) и [план](../ROADMAP.md).
- Публичная документация: https://newmishka.gitbook.io/inbox-weaver-dokumentaciya/
- Открытая лицензия [MIT](../LICENSE) с сохранением уведомления об авторских правах NewMishka.

## Проверки и статус

Release workflow повторно запускает полный набор автоматических тестов, проверку синтаксиса, `git diff --check`, воспроизводимую сборку XPI и `unzip -t` непосредственно перед публикацией.

XPI и файл `SHA256SUMS` прикладываются к GitHub Release `v2.0` и собираются из того же commit, на который указывает release/tag. Основная исходная ветка не содержит бинарных артефактов.

**Статус 2.0: предварительный выпуск до ручной приёмки.** Протокол [P-001–P-057](PRODUCTION_TEST_PROTOCOL.md) ещё не содержит фактических PASS/FAIL. Подтверждённой production reference остаётся 1.0.162. Не присваивайте 2.0 статус production лишь на основании автоматических тестов.

## Установка и обновление

Сохраните правила в JSON из предыдущей версии. Скачайте XPI со страницы GitHub Release и установите через управление дополнениями почтового клиента. Проверьте сохранение настроек и правил, Live-режим, ручное сохранение и XLSX на тестовом профиле. При откате сохраните предыдущий XPI и данные профиля, затем сверяйте результаты с reference 1.0.162. Подробности: [руководство](USER_GUIDE.md).

## Известное ограничение

В Thunderbird 154.0 вызов `messages.listAttachments` для отдельных писем может вернуть общий `An unexpected error occurred`. Расширение записывает ошибку в аудит, помечает письмо и продолжает обход. Фактическую частоту и поведение в целевой версии почтового клиента нужно установить вручную.
