# Security Policy

## Поддерживаемая версия

Исправления безопасности готовятся для актуальной публичной линии InboxWeaver. Версия 2.0 пока имеет статус pre-release.

## Сообщить об уязвимости

Не публикуйте эксплуатационные детали уязвимости в обычном Issue.

Предпочтительный канал — GitHub **Security → Report a vulnerability** (private vulnerability reporting). Укажите:

- версию InboxWeaver;
- версию почтового клиента;
- краткое описание риска;
- минимальные шаги воспроизведения;
- что именно может быть раскрыто, изменено или выполнено.

До исправления не прикладывайте реальные письма, адреса, вложения, пути профиля, токены или диагностические выгрузки без обезличивания.

## Область внимания

Особенно важны сообщения о небезопасной работе с вложениями, путями загрузки, диагностическими данными, импортом правил и внешними ссылками.
